## 阶段二：工单操作完善

### 2.1 工单操作 API

需要实现的端点：
- `POST /api/tob/tickets/:id/assign` - 分配
- `POST /api/tob/tickets/:id/reassign` - 重新分配
- `POST /api/tob/tickets/:id/escalate` - 升级
- `POST /api/tob/tickets/:id/close` - 关闭
- `POST /api/tob/tickets/:id/priority` - 修改优先级
- `POST /api/tob/tickets/bulk/assign` - 批量分配
- `POST /api/tob/tickets/bulk/close` - 批量关闭

### 2.2 工单详情页增强
