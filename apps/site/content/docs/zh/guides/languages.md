## 产品配置

产品支持英语和中文，可用语言必须包含编写内容的默认语言。启用多种语言需要有效
Translation AI 路由。编写第一个非系统工单类型后，产品默认语言不能再改变。

类型和表单基础文本使用默认语言，`*I18n` 仅保存显示文本。字段 key、选项 value、
条件和提交的 metadata 保持语言无关。租户预设以英语为基础，复制时按目标产品默认
和可用语言重新安排基础及翻译文本。

## 门户语言解析

依次使用显式 `?lang=`、`onfire-lang` cookie、受支持的 `Accept-Language`，最后
回退到产品默认语言。切换器只展示产品可用语言，单语言产品隐藏切换器。切换时保留
选择的类型及仍兼容的表单草稿值。

## 原文与必要翻译

工单/回复基础列保留作者原文，翻译映射单独缓存。有效网页/邮件新工单在验证、过滤后，
写入前完成必要翻译。客户、ToB、邮件和 MCP 的公开回复同样先翻译后保存；失败时
返回/记录错误，不保存未翻译的替代结果。内部备注不触发客户可见翻译。

客户 API 只投影一个解析后的语言，不暴露翻译映射、其他原文、检测语言信息、内部
备注或 AI 字段。ToB 保留原文用于审计，并可展开查看客户侧回复翻译。外发邮件复用
已保存的客户语言投影，不再次付费翻译。

工作台中英文界面偏好与产品编写语言不同，改变界面语言不会重命名字段 key 或改写
历史内容。
