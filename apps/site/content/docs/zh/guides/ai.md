## 任务与提供商

| 任务 | 支持范围 / 用途 |
| --- | --- |
| `agent` | OpenAI、OpenRouter、Anthropic、Google、xAI、DeepSeek，工作台助手 |
| `prescreening` | 上述语言提供商或 TypeSafe/Jev，分类、固定标签和邮件类型选择 |
| `spam` | TypeSafe/Jev、上下文 Hugging Face 分类、Decision HTTP，真实沟通接收判断 |
| `prereply` | 语言提供商，客服建议回复 |
| `translation` | 语言提供商，产品文本、工单和公开回复翻译 |
| `embedding` | OpenAI、OpenRouter、Qwen、Jina、Cohere、Google |
| `rerank` | OpenRouter、Cohere、Jina |

Jev 返回类型化判断，不生成摘要或新的问题描述。分类器和 Decision HTTP 不能生成
回复、翻译或向量。OpenAI 支持 Responses（默认）或兼容网关的 Chat，OpenRouter
使用 Chat。模型 ID 按任务能力验证，运行时也验证输出。自定义地址必须是公开 HTTPS，
不含查询、片段或重定向。

模型选择框支持按 ID 或显示名称搜索，搜索不会修改已选模型。可用方向键和 Enter
选择、Escape 关闭，或刷新提供商列表；仍可直接编辑自定义模型 ID。OpenRouter
分别拉取文本、向量嵌入与重排目录。与索引维度不兼容或尚未确认的向量模型会显示
说明并在列表中禁用。

## 范围配置

凭据与功能路由分开创建。每条路由是有序的凭据/模型组合，同一凭据可用于多个兼容
功能。产品默认继承租户，再继承系统；可以覆盖，包括明确禁用。系统 AI 仅限
SuperAdmin，租户/产品管理员管理自己范围。子范围可选父凭据，但不能查看保存的
密钥，秘密字段加密保存。

启用功能需有有效分配。多语言产品需要翻译路由，邮件 AI 预筛需要预筛路由。
真实沟通过滤单独在[反垃圾设置](/docs/zh/guides/spam-filter)启用，并在客户
网页/API/邮件写入前执行，与创建后的工单分析不同。

## 故障切换与用量

运行时跳过禁用或冷却中的凭据，提供商/协议失败后切换到下一个可用分配。失败密钥
只有在存在其他候选时才进入可配置冷却，最后一个候选不冷却。统计记录失败不会重复
执行已经成功的模型调用。提供商不可用时仍可修改名称、禁用和冷却等元数据；更换
密钥、提供商或地址可能需要重新验证路由兼容性。

每次请求记录凭据、提供商、返回的实际模型、成功状态和系统/租户/产品维度 token。
保存时间可以按天配置或永久保留，cron 删除过期明细与汇总。分类接口可能不报告
token；零个已报告 token 不代表提供商免费。

## 知识与向量空间

结构化产品知识在产品/模型独立命名空间中建立索引。维度来自绑定的 Vectorize
索引，示例配置为 1024，运行时支持最多 1536。结果必须恰好具有该数量的有限数值，
不能自动补齐或截断不兼容向量。

Embedding 回退凭据必须使用相同提供商、地址、模型与维度。有效向量空间变化会触发
持久化、带租约的重建，包括继承配置变化。知识页显示进度并提供重建操作。待处理
条目仍可通过范围内 D1 回退检索；重排数量受限，不可用时保留检索顺序。

## 源文档限制

上传支持 PDF、文本、Markdown、DOC 和 DOCX，最多 10 MB。`ready` 只表示原文件
已安全保存在 R2，**尚未实现自动文档文本提取和索引**。检索请使用结构化知识条目，
不要把上传成功理解成 AI 已能搜索该文件。
